# AI Employee 360 - Zoho People Web Tab (ZET)

This folder contains the **Zoho Extension Toolkit (ZET)** frontend widget for **Zoho People**, wired directly to your deployed Zoho Catalyst function:
```
https://employee360-ai-60085182165.development.catalystserverless.in/server/employee_360_ai_function/
```

---

## Folder Structure

```text
frontend/
├── plugin-manifest.json   # Zoho Extension manifest declaring the Web Tab
├── package.json           # ZET npm scripts
├── README.md              # Setup and packaging guide
└── app/
    ├── index.html         # Main Web Tab entry point with Zoho People SDK
    ├── css/
    │   └── style.css      # Responsive styles & dashboard theme
    └── js/
        ├── config.js      # Catalyst Cloud endpoint configuration
        ├── zohoPeopleSdk.js # ZOHO.embeddedApp bridge & context extractor
        └── app.js         # Reactive data loaders and AI interface
```

---

## 1. Local Testing with ZET

Ensure you have the Zoho Extension Toolkit installed globally:
```bash
npm install -g zoho-extension-toolkit
```

Navigate to the `frontend` directory:
```bash
cd frontend
zet run
```

This starts the local SSL widget server at `https://127.0.0.1:5000/app/index.html`. You can validate it inside the Zoho People developer sandbox.

---

## 2. Packaging for Zoho People Web Tab Upload

When you are ready to upload to Zoho People:

1. Inside the `frontend` directory, run:
   ```bash
   zet pack
   ```
2. ZET validates `plugin-manifest.json` and creates a zip file inside `dist/` (e.g., `dist/ai-employee-360-1.0.0.zip`).

---

## 3. Uploading to Zoho People Console

1. Log into your Zoho People account at:
   **[https://people.zoho.in](https://people.zoho.in)**
2. Click **Settings** (Gear icon in top navigation) &rarr; **Developer Space** &rarr; **Web Tabs** (or **Widgets**).
3. Click **Add Web Tab** (or **Upload Widget**).
4. Enter:
   - **Tab Name**: `AI Employee 360`
   - **Source**: Select **Widget / Extension**
   - **Upload**: Choose the `.zip` file generated by `zet pack`.
   - **Roles / Visibility**: Select Administrators and HR Managers (or All Employees).
5. Click **Save**.

The **AI Employee 360** Web Tab will now appear in your Zoho People sidebar navigation and automatically communicate with your live Zoho Catalyst backend!
